**审查时间**: 2026-07-09 00:10
**审查范围**: 前端 (E:\smart-light-front) + 后端 (E:\smart-light-backend) + 8266 固件 (E:\8266_OTA)

## 8. 修复建议分级

### P0 — 立即修复

#### P0-1: luxAutoTarget 全链路闭环
- **问题**: 固件支持但后端/前端完全缺失
- **影响**: 自动亮度调节功能无法远程控制，用户体验断裂
- **改哪一端**: 后端 + 前端
- **最小修复方案**:
  1. 后端 `DeviceDO` 加 `lux_auto_target` 列 (INT, 默认 300)
  2. 后端 `DeviceSaveReqVO` / `DeviceRespVO` / `DeviceStateReportReqVO` 加 `luxAutoTarget` 字段
  3. 后端 `WebSocketPushService.pushStateToDevice()` 加 `payload.put("luxAutoTarget", ...)`
  4. 后端 `DeviceReportServiceImpl.reportState()` 加 `device.setLuxAutoTarget(reqVO.getLuxAutoTarget())`
  5. 前端 `DeviceCreatePayload` 加 `luxAutoTarget?: number`
  6. 前端 `LampDeviceCard.vue` 加滑块 (仅 autoMode 时显示)
- **验证**: 前端调节 → 后端存储 → WS 下发 → 固件接收 → state-report 回传

#### P0-2: luxAutoBrightness 接收存储
- **问题**: 固件上报但后端不接收
- **影响**: 自动亮度计算值丢失
- **改哪一端**: 后端
- **最小修复方案**:
  1. 后端 `DeviceDO` 加 `lux_auto_brightness` 列 (INT, 默认 50)
  2. 后端 `DeviceStateReportReqVO` 加 `luxAutoBrightness` 字段
  3. 后端 `DeviceRespVO` 加 `luxAutoBrightness` 字段
  4. 后端 `DeviceReportServiceImpl.reportState()` 存储
- **验证**: 固件上报 → 后端存储 → 前端展示
